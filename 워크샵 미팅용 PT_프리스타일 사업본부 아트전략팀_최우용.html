위 사례는 적용 제안이며, Adobe의 현재 기능만으로 전부 일괄 자동 구현된다는 뜻은 아닙니다. 툴 스크립트·연결 방식·승인 절차를 별도 검증해야 합니다.

08 · MCP EXPLAINED

MCP는 무엇을 바꾸나?

MCP(Model Context Protocol)는 AI 에이전트가 지원되는 외부 도구와 데이터에 접근할 수 있도록 연결하는 규약입니다. 자동화 자체를 완성하는 도구는 아닙니다.

INPUT디자이너의 작업 지시
→
ORCHESTRATIONAI 에이전트
→
CONNECTIONMCP 서버 / 도구
→
ACTION디자인 앱 · 파일 · 문서

예시 지시

“완성된 이벤트 배너 원본을 기준으로 3종 사이즈를 제작하고, 텍스트 영역을 점검한 뒤 정해진 파일명으로 출력해 줘.”

가능 여부는 연결된 MCP 서버의 기능, 스크립트·API 지원, 파일 구조, 승인 절차에 따라 달라집니다.
